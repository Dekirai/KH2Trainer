=============================

Research checkpoint for the immutable v0.12.6 baseline. No product, hook, native test, game process, input, save, mod or Twitch action was performed.

Result
------
ActorGeneration plus STATUS address and exact field bits is insufficient. A level/equipment/form refresh can rebuild the same live Actor's same STATUS and produce the same values. Its backlink and refcount need not change. No existing monotonic STATUS revision was found in the observed 632-byte layout.

56 fresh complete IDA bodies contain 3440 instructions and 15150 original code bytes. The verifier also checks 839 data/fragment bytes, exact retail SHA, complete page cursors/counts, and an independent Capstone decode at every ASM address. The 47-byte allocator tail 3C0250 is a separate code fragment, not an invented IDA function. Evidence was read from existing ready session de3f97b1; the IDB was not changed.

Five scalar fields
------------------
STATUS+430: General received-hit coefficient, BYTE, native initializer default 100.
STATUS+520: Draw, Float32, native initializer default 0.
STATUS+568: Jackpot, Float32, native initializer default 0.
STATUS+572: Lucky, Float32, native initializer default 0.
STATUS+580: Munny retained factor, Float32, native initializer default 1.

Incoming writer graph
---------------------
3C0010 initializes an allocation, sets coefficient 430=100 and calls 4016B0.
3C1D90 rebuilds a character STATUS:4016B0 resets the ability block; coefficient 430 becomes 100;3C1190 applies equipment;4014A0/401730 apply equipped abilities. Ability 405 changes Draw,406 Jackpot,407 Lucky and 540 retention.
3C2100 is saveback then rebuild on exactly the same STATUS. Both direct character acquisition 3C0620/3C02E0 and UI preview 3C03F0 also reach 3C1D90.
Ordinary EXP 3ECF30/3ED190, form-level 3E8380/3E8AA0, summon-level 40D530/40D6E0 and UI/cache 2FC760 call 3C2100 directly. The Sora/Roxas 404F70 and Mickey 4154A0 virtual adapters at descriptor+280 are only one subset.
3C2240 writes enemy coefficients from parameters; its two known callers first call 3C0010. Script 431200 independently calls 3C2650, whose signed index 6 overwrites General 430. It has no native index bound.

Allocation identity is separate
-------------------------------
3C04E0 returns an existing allocated character STATUS and increments 612, or creates one. 612 is a refcount,616 a packed Actor backlink,504 the ability owner selfpointer; none is a rebuild generation.
3C07E0 saves volatile data, decrements 612 and returns a slot to the free list when<=0. It leaves scalar bytes/backlinks in place.
3C1880 resets the whole free list/count 80 without resetting scalar fields.3C0840 calls it. Observing only individual init/rebuild calls cannot accurately describe that intermediate pool lifetime.
Actor and STATUS may have different sharing/reference lifetimes. Metadata should track 80 pool slots without writing native refcounts. Existing ActorGeneration remains an additional independent binding.

Minimum conditional observation contract
----------------------------------------
0x1403C0010: before any original writes; RCX=STATUS; return same pointer RAX. new slot-allocation serial; invalidate prior status leases even at same address.
0x1403C1D90: entry, before original; RCX=STATUS,RDX=nullable CharSave; native RAX preserved. increment whole-cohort rebuild revision even when final bits equal; a conservative revision on no-op early return is acceptable.
0x1403C2650: before original store; RCX=STATUS,EDX=signed index,R8D=signed percent; native RAX preserved. General revision for index 6; reject observation confidence on unsupported/corrupt index instead of assuming a bound. Native original still forwards unchanged.
0x1403C1880: before reset; RCX=pool base; native return preserved. increment pool epoch and invalidate old slot allocations.
0x1403C07E0: before reference release; RCX=STATUS; preserve original return. retire a slot if valid pre-refcount==1; malformed counts lose confidence. Do not label Actor dead.

Known 4016B0/401730/3C1190 code callers are contained within 3C0010/3C1D90. Known 3C2240 callers first initialize a newly allocated slot. A broader boundary contract may also observe 3C2240,4016B0 and 401730 to tolerate externally initiated calls to these public helpers. The bounded candidate scan is supporting evidence, not a whole-program no-other-writes proof.

Every observation must invalidate before the relevant original writes, including same-value writes. A conservative invalidation on an early no-op return is safe; pretending a failed/partial rebuild did not happen is not. Pool epoch, slot allocation serial, rebuild revision and selected field revisions must not reuse tokens. Overflow or observer loss blocks restore and reports uncertainty rather than Actor death.

Manual Loot/DamageTuning commands are direct stores and must participate in the same writer revision. Acquiring a typed lease must capture original/applied bits, exact current actor/status binding, owner and revisions in one game-thread transaction. Separate field masks permit overlapping-duration rewards on disjoint fields; whole-cohort rebuild invalidates all five. Do not recapture a new baseline automatically after native takeover.

Observation continues during off-current/menu/host-expired phases. Command admission and restore require a freshly coherent current role, actor generation, allocated slot/backlinks, intact observation and matching revisions/values. An off-current live Sora is not retired merely because Mickey is controlled. Native originals always forward exactly once; metadata errors cannot swallow native calls or native exceptions.

Implementation boundary
-----------------------
The minimum entry set is direct code, not one replaceable vtable. Derived+280 hooks miss level/reward direct calls; VM record 7566E0 covers only the coefficient script adapter. An approved, complete interception mechanism with relocation/unwind/concurrency proof is still required. No hook is implemented or authorized by this report.
This report establishes a bounded native call-graph contract, not an approved inline-hook implementation. There is no product patch in this checkpoint. A claim covering arbitrary mod writes or corrupted pointer/index behavior would exceed the evidence.

Roles and visible effects
-------------------------
Sora: Shared STATUS layout and all five consumer paths; normal native form/mission rules remain.
Roxas: Shared constructor/rebuild/Draw/party-quantity/damage paths. Match character 14 and forms 0/10 through existing role classifier; do not infer role from the shared Sora save.
Mickey: Shared structural layout and rebuild; Draw, quantity and damage-coefficient consumers remain applicable. Normal prize 3DC170 remaps toDrive orbs and suppresses ordinary Lucky item rolls; retention is bypassed for the remapped 7/8 kinds. Do not market Lucky/Tax effects as effective in ordinary rescue-Mickey mode.
admission: Structural role compatibility is not a release-ready timed reward. Ownership observer/receipt implementation and role-specific tests are still required.

Verification and remaining limits
---------------------------------
No live game or hooks executed; no product/test/build changes.
No universal proof excludes arbitrary external memory writes, corrupted resource-derived indices or unexamined computed-address/bulk writes. Exact retail path pinning is a conditional contract.
The candidate scan covers 0x1403A0000.0x140435000;185796 decoded instructions,188 skipped data bytes. It intentionally records offset collisions and does not turn all matches into STATUS writers.
The 47-byte allocator tail at 3C0250 is not defined as an IDA function; its original bytes are captured as a code fragment, excluded from full-function and claim totals.
No artificial native revision field should be invented from STATUS 612(refcount),616(backlink),504(selfpointer) or unused padding.
The offline candidate scan is limited to 0x1403A0000.0x140435000 and the specified displacement forms. It includes collisions with HUD/motion/attack objects and must not be treated as a global alias analysis. Computed-address/bulk writes and other modules remain explicitly outside a universal guarantee.
