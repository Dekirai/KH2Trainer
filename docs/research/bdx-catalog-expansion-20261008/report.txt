Reproduce from repository root
py -3 -B docs/research/bdx-catalog-expansion-20261008/verify.py --check
pwsh -File docs/research/bdx-catalog-expansion-20261008/run-probe.ps1 -Check

The first command checks the full manifest, source pins, upstream manifests, deterministic builder and independent original-PE/text receipt without writing evidence. It needs the pinned retail EXE and repository sources. The second builds the source-based probe into artifacts/bdx-catalog-expansion-study-probe and compares its output with compiled-probe.json. Use -OutputDirectory for a different external build folder.
