Why these boundaries

Initializer 02CD40 independently reads this pointer, adds 0x8000 bytes and stores 2AF8C78. The following cluster also contains QWORD 756AA8, masked by 02CD10. Continuing blindly to the next registered bank would misclassify this data as callbacks. No source-language array declaration or native count field was recovered. The explicit original-data clusters justify capture extents, not a safe index limit.
