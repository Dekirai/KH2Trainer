Purpose and API
GameplayStateSnapshot(freshContext) reads native game state after the engine update.
GameplayStateCapabilities publishes slots456..462. Root owns publicationTick463.
The module issues no native function calls, game writes, save writes, hooks or input.

Main findings
- Pause menu9006B0 and window taskAC0F48 are menus. AC0F48 is not a cutscene.
- Event context2A11478 has an explicit allocation/publication/cleanup lifecycle.
  All native event modes conservatively suspend rewards, without dereferencing
  event resources or assuming that every event mode disables every input.
- Native player input3B2340 checks descriptor-vcall120, controller lock+36bit1
  and global input lock2A10500. Both supported player classes use3A8E90.
- The observer reproduces the shared native predicate, validates the live
  vtable120 function pointer, and checks the controller/actor/pad association.
- Actor stop, pending room/Drive transitions, zero HP, tutorial windows and
  incomplete/unrecognized state remain separate external reasons.
- Timer ownerABB854 alone is not an input lock: script entry4335D0 can pause
  a timer. Foreign timer owners conservatively produce Unknown.
- Trainer pause/freeze ownership is matched against existing WorldFeatures.
  External reasons remain present while a trainer effect is active. A timed
  reward may ignore only its own pause bit; it must not ignore Unknown/Menu/
  Cutscene/Transition/Dead/InputBlocked or another trainer effect's bit.

Test scope
Normal Sora/Roxas/Mickey, unsupported roles, loading/menu/event/transition/death,
native controller and pad locks, owner-loss, simultaneous self/external blockers,
foreign timer owners, stale heartbeat/wrap, wrong thread, access faults, pointer
drift and first/last drift of every pin. Snapshot reads leave every byte of the
synthetic game image unchanged. The role inspector itself is covered by pe's
separate955-check Drive/role suite; this module's fixture stubs that dependency.

Limits
No live injection or gameplay test was run. Passing the observation means the
documented control predicates pass; it does not promise every action is legal
during every animation. Unknown controllers/code changes fail closed. Native
event modes and script-paused timers may be conservative false negatives.
Existing World ownership has no native generation token for same-value foreign
writes. Per-frame reads and SEH do not constitute a lock against arbitrary mods.
AC183C (camera bank) and2A0D628 (background resource requests) are deliberately not
mislabelled as cutscene state.
