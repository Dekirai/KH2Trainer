=============================

Limits: this is not a universal speed or gravity multiplier. Special Actions can use other movement rules. High Jump can override the base jump height, and an active jump is not restarted. No retained pointer, native call, hook, auto-restore, save edit or automatic reapplication was added.

Manual one-shot native support does not establish timed restore ownership.
