FORCED NATIVE DRIVE — v0.4 IMPLEMENTATION CONTRACT

Ownership: DriveFeatures.inl only; Common bridge/C#/protocol remain root-owned.
ABI: void __fastcall(Actor* RCX,int EDX) at RVA40CE60. Native AL is ignored.
Commands122/123/126; readouts124/125/127. Phase/result enums in drive_forced.json.

BEHAVIOR
Trigger1..6 is deterministic and cost-free. No Drive bar, unlock item, minimum
party size or ordinary command-availability requirement remains. Active form,
including the requested form itself, first queues native Revert. The second
step uses freshly rebuilt context after actual new base Actor, pendingContext0,
transition lockbit2 clear and suspended-party count0. Locked form record defaults
are accepted without granting items. Native HP/MP restoration, equipped data,
form timers, normal consumption and automatic Revert remain in effect.

QUEUE / CLEANUP
Queue binds full10-byte room key, heap and both scheduler identities. It stops
on observed scene/room transition, title/event, host expiry, bridge disable or
30-second overall timeout. In-flight native context address, original Actor,
form and task pointer are checked every observed pending frame. Cancel and
reset drop only trainer follow-up; they never free/cancel an engine fiber.
Completion requires a different Actor address and matching Actor/Save form,
status linkage/rebuild readiness and positive completed form timer. The engine
allocates the new Actor before deleting the old one. Requested form readout
is retained after completion/cancellation. Last-result readout tracks the queue;
early rejected clicks are reported separately in the command log.

SAFETY GATES RETAINED
Living unattached Sora, actual controller/status/backlinks, stable playable scene,
no cutscene/summon/capture/freeze/pause/transition/special-action owner, bounded
complete Actor list, correct first-active Sora statuspool entry and refcount,
correct live Save header and status pointers, bounded equipment/abilities/level,
valid model/costume/party data, finite timer/area data, exact entry bytes, valid
message29 override index0..5 and Anti text/fallback resource. Ordinary Drive
prohibition bits and gauge-mode availability checks are deliberately omitted.

LIMITS
No live or UI tests were run in this release. Fake memory tests validate trainer
routing/guards/lifecycle; they do not prove rendered form assets or native
resource loading. Native future allocations and asynchronous recursive assets
remain engine assumptions. Exact address/field/task ABA reuse entirely between
frames cannot be distinguished without a separate generation token. An untouched
locked form may have empty native abilities or optional offhand weapon. No raw
form-ID write, save export, artificial unlock, gauge fill or rollback is used.
Normal gameplay and the native status-save transfer can still persist changes.

ADDRESS-SPECIFIC FINDINGS
RVA 0x40CE60
Direct native entry takes Actor* in RCX and signed form ID in EDX; 0 means Revert,1..6 are forms. AL is not a success result. Entry owns creation of a56-byte asynchronous transition context.
Evidence: drive_forced_evidence.json dedicated45-instruction ASM and decompile
Limit: Entry ignores its internal actor-liveness Boolean and assumes engine allocation success; caller must validate current Actor and scene.

RVA 0x40CAA0 / 0x40CF20
Context contains original Actor+0, form+8, nativeTask+40. Constructor can cancel/replace an existing global context. Cleanup conditionally clears global2AE9FA8, releases2A10504 bit2, restores suspended partners.
Evidence: drive_forced_evidence.json; drive_forced_lifecycle_evidence.json
Limit: Address/source/form/task binding detects observed replacement. Exact ABA reuse of every bound value between observations is unobservable without an engine generation token.

RVA 0x40D000

Evidence: drive_forced_evidence.json dedicated280-instruction ASM and decompile
Limit: Resources can be loaded asynchronously; preflight validates referenced tables/models but cannot guarantee later allocation or recursively loaded asset success.
