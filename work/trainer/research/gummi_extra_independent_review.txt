Native ABI
225DE0/225CD0/225DB0 use RCX state and EDX checked delta for signed fields +36/+40/+44. 230BD0 uses RCX inline combo, EDX base points; return is deliberately ignored. It reads combo+8, ship+200, state+52. All nine complete byte signatures match the supplied byte evidence.

Integer and float conversion
Target-minus-old is computed in int64 and rejected outside int32. Combo gain reproduces Float32 bonus/100+1 and multiplication before truncation. The upper conversion bound 2147483520 and int64 progress sum exclude positive CVTTSS2SI and signed ADD overflow. Native stock conversion is bounded by nine iterations, retains progress100 and bit4 at saturation.

Object lifetime
Gummi-specific BuildContext verifies module membership, heap and scheduler, current ship and embedded state backlinks. Actions require running mission phase8, ship phase2, living HP, no rebirth/dead flags, game thread and a fresh nonzero heartbeat. The handler rebuilds and compares current identity and relevant inputs before a single call; it reads no game pointer afterwards. No persistent pointer or automatic replay is stored.

Resource semantics
Mobility and roll use the current playerparam row0. Negative mobility uses the first matching systemparam row0. Resource scans are bounded and full ranges readable. Lock-on rows are verified inside the loaded 128-byte-row table with expected IDs, finite nonnegative parameters and finite proposed products. Current lock-on timers are preserved; future reloads consume the new bonus.

Companion-only completion delta
Native 230D20 accepts phase2/index5, increments it to6 at 230E07 and stores phase4/index6 at 230E41/43. Phase4 advances to5 without clearing that index. The final source allows index6 only in phases4/5, while phase1 still requires index<5. This fixes the earlier temporary loss of charge controls/readouts in a legitimate state.

Limits
