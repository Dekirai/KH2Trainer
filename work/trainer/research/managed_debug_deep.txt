MOST USEFUL NEW CONNECTIONS
Texture association editor:
Native1A26E0, under converter object byte+2372, invokes CLR bridge579BE0 with a
temporary PNG path. Actual thunk entry jumps to747C50; alternate entry579BE4
uses747C48. The CLR fixes these slots up; neither disk token nor IL-RVA is callable.
CIL31B0 copies path to global s_local_texture(BF2040), starts a WinForms thread,
and joins it. D040/D950/DA90 show source PNGs and target TM2 previews. Native shared
structure s_tex_anim(AC7140) has size0x2C4; source selection stores up to ten32-byte
basenames at+0x184. Native caller resumes only after form close.
This is an offline asset-association workflow, not an in-game render inspector.

Concrete legacy limitations:
31B0 passes path as sprintf format; no size/format safety or apartment setup.
DCC0 does not clear unused trailing selected-name slots, so reducing a previous
selection can retain old names. It copies basename-length bytes into32-byte slots
without a31-byte bound. DD90 cancellation zeroes the full shared structure.
D950 writes intermediate C:/tmp/*.tm2.bmp through TinyTexEntry.BMPDecode.
DDE0/DE40 ignore the selected-item enumerator's MoveNext result before Current.
D8B0 creates Graphics/Brush objects without explicit disposal in that body.
These are static defects/assumptions; no exploitability claim or execution.

Graphics/audio controls are narrower than their names suggest:
BE00 sets EnableGlow(ABD148), but only native169180 reads it when allocating and
initializing glare objectABD198, setting that object's byte+8. No current-frame
lighting/fog control follows. Recreating this allocator-backed object is not a
safe trainer operation inferred merely from the menu.
BE40/BEB0 set DesableScd(79CFD0).14ED40 skips audio initialization when set;
3A64F0 skips ORIGIN audio replacements for BAR types1F/22/30. This is not ordinary
mute and must not be toggled as a runtime mixer control.
BF00's drive-prefix substitution calls148660; this build's148660 clears260bytes
at8BC190 and returnsfalse. The managed substitution branch is therefore inactive.

Window/input lifecycle:
CIL2380 starts internal BaseSimpleForm. It does not start external-dependentKH2Form.
C7E0 initializes input and device notifications; C830 initializes GX from HWND/App.
C300 marshals closure to UI thread; C350 schedules a timer; CF70 closes on that tick.
CC40 releases clipping and hides-count ownership on deactivation.
CDD0 has a SteamDeck-specific1x1 center clip; regular mode clips client rectangle.
CED0 forwards native mouse-active flag even when overlay prevents cursor hiding.
CF20/CF40 couple GX suspend/resume with conditional audio pause. ForceSuspending
prevents premature resume during user-close confirmation.
These functions own the real renderer/window lifecycle; instantiating a second
developer form would duplicate device initialization/teardown, not add an overlay.
