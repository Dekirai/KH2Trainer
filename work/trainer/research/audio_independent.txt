Main result
A bus gain stage is suitable for a future playback-preserving volume control.
The music wrapper1388F0 is unsuitable for mute because gain<=0 calls Stop0818B0.
The native bus setter07FAD0 does not have that stop branch.

Recommended candidate chain:
  079C90(localController, busID)
  07FAD0(localController, gain, 1)
  07F7E0(localController)

ABI:
  Constructor: RCX=24-byte output controller, EDX=unsigned busID.
  Setter: RCX=controller, XMM1=float gain, R8D=milliseconds.
  Destructor: RCX=controller.
  Input range for a trainer: finite gain0..1 and a known fixed bus ID.
  ID0 means master. Positive IDs index the current list as ID-1.
  These APIs do not return a success boolean.

A duration of1ms updates only DynamicValue fields in ordinary Bus0A54D0,
MasterBusXA20A8830 and generic MasterBus0C4B80. Immediate ordinary-bus mode
traverses the voice list. MasterXA2 immediate mode calls voice SetVolume.
The regular update0A4F70/0A88C0 subsequently evaluates/applies the interpolation.
This confirms a path distinct from Stop; audible behavior has not been live tested.
The native updates contain their own voice-list work, so delaying the setter is
not a substitute for lifecycle and thread correctness.

Lifecycle findings — important before implementation
Global Sound CS at2B81278 is initialized by CRT initializer001000 and deleted by
at-exit571EB0. It exists for process lifetime, not just while a scene plays.
Native public sound APIs use it, but the final driver teardown is outside it.

077BE0/077A30 first stop and join audio workers through07B5B0/07B380.
They then destroy helper objects and SoundDriver2B81DE0.
091470, the driver destructor, calls08FA20.
08FA20 destroys all ordinary buses, frees buslist2B811C8 and destroys
master2B811D0. It does not null buslist, master or buscount2B811A4.
The outer teardown nulls driver2B81DE0 only after the destructor returns.

Consequently:
  * Readable memory and expected vtables do not prove a live audio object.
  * Taking the public Sound CS alone does not serialize final destruction.
  * A nonzero driver pointer can coexist with an in-progress destructor.
  * A trainer must run at a proven serialized engine lifecycle point.
  * No GUI-thread/worker call, cached bus pointer or teardown callback call.

08D720 resets and builds the master/list;08E150 assigns busID=index+1.
08DB30 can publish another MasterBusXA2. Driver identity alone is therefore
insufficient: bind driver, master, buslist, count, selected object and bus ID.
079C90/0936A0 produce a non-owning controller.07F7E0 only restores its vtable.
The controller has no reference count or lifetime pin.

Gain readback and restore
Ordinary bus first gain stage:
  current+32, target+36, step+40, remainingMs+44, totalMs+48,
  start+52, parentMultiplier+56, curve+61.
0A5430 returns a product of several stages, not the raw stage to be restored.

A conservative future lease should acquire only a stable finite original stage
(remainingMs==0), save its target, and bind all current object identities.
Use target to recognize ownership because current may lag during interpolation.
If native settings or another owner changes target, cancel the trainer lease.
Restore only when the same live identities and owned target are still current.
Do not restore through old pointers after device reset/teardown/track replacement.
An in-progress original envelope cannot be faithfully restored by saving one float.

Pause/resume contract
081B70(controller, milliseconds) pauses.081C70(controller, milliseconds) resumes.
Duration0 means immediate operation; the second argument is not a bool.
0812B0 validates,081EB0 queries activity,081FF0 queries paused state.
The low-level methods resolve positive generation-bearing IDs through09A890
under backend locking, or negative IDs through the controller's layout.
Copying a controller does not retain the negative-ID layout or the voice.

High-level music entries are72 bytes in list713470:
  +8 next, +16 SoundController, +48 channel, +60 pause-owner flag,
  +62 type(1=music), +64 stored baseline gain.
13C470 removes/frees invalid or inactive entries.
1DC770 registers1DC370 at outer scheduler priority500010;1DC370 calls13C470.
This establishes an engine cleanup path, not universal thread safety for every
list access. The high-level wrappers themselves do not lock the entry list.
13C910's CThread-derived object alone does not prove that list handling is on a
separate thread; backend workers independently exist and are joined at teardown.

138E80 coordinates native global pause/duck with manager8BBD08+68 and entry+60.
The paused query does not reveal who owns the pause. Automatic resume on disconnect
could defeat a menu pause. A safe pause feature still needs a native-owner handoff
design and must operate only on the freshly verified current entry/controller.
