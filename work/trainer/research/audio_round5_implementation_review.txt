Result: no blocking issue found in the reviewed frozen module, catalog or tests.
Reviewer: pe_inventory. No files belonging to another agent were edited; no build or live action was performed.

Checked behavior
- Lock order and cleanup: Capture enters global Sound CS first, then the captured manager CS+776. Both ranges must be writable. Nested finally releases inner then outer on early return and SEH, including an inner-release exception. IPC dependent fields publish only after capture returns. A failed acquisition is not released.
- Lifetime: Uses existing Audio ThreadReady plus driver/master/list graph checks. Manager/layout ranges, exact vtables, reciprocal backlinks and byte816 are checked before manager lock entry and rechecked after entry/copy. Existing Bridge OnFrame calls TrainerFrame only after originalUpdate returned0 and verifies the active app and recorded engine thread. Byte816 is correctly not treated as a generation token.
- Full membership before selected: Capacity/count/peak and the full capacity array are bounded. Every counted member is validated for range, exact vtable/kind, nonzero ID, owner backlink and uniqueness. Selected+120 is compared as an address only; member fields are taken from the validated copy. Delete-ID/Delete-All ASM leaves selected unchanged, so this guard addresses a real stale-pointer case.
- Selection semantics: Enabled bit0, uint32 ID and priority, maximum unsigned priority, and later member on ties match the full native072070 path (CMP followed by JA skips only a strictly smaller candidate). Zero priority is valid. All three exact kinds and full-width IDs remain representable in double.
- Invalid versus zero and cache meaning: 408 is an intentional valid readiness0 on failure; dependent values are omitted. Empty or no-active lists retain valid structural zeros. Active fields are published together only for the current validated winner and finite cached position/matrices. Position is manager cache from the last native update; it is not recomputed from a newer listener matrix. Unknown manager+148 is ignored. Common snapshot validity reset prevents old values surviving into a new frame.
- Scope and fault handling: No listener/audio game function, controller getter, callback, allocation, settings mutation or persistent effect is introduced. Ordinary Reset is unnecessary. Exceptions propagate through the existing Bridge failure path after cleanup; the module does not promise recovery from a broken native lock.

Limits
- Native normal application Init/Update/Shutdown ordering is essential; foreign-thread private teardown or corrupt external writes are outside this static contract.
- Pointer identity is not a generation token, and the cached transform lacks a frame timestamp.
- If LeaveCriticalSection raises before releasing a broken native lock, finally still attempts the outer release, but recovery is not guaranteed. Existing Bridge fault handling stops retries and continues exception propagation.
- The bounded duplicate scan is O(n^2) at1024 entries and uses about24KiB of stack while locks are held. No live audio latency or performance measurement was performed.
- No audible-output or speaker-channel claim is made.
