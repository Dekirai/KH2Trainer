ASSET FINGERPRINT CORE INDEPENDENT REVIEW

No blocking unresolved finding in the final reviewed Core state.
Read-only review of fingerprint factories, payload-identity metadata, bounded JSON/streams, explicit local save/load, and the focused tests. No independent build or filesystem probe was run this round.

RESOLVED FINDINGS
Public PackageAssetInfo/RemasteredAssetInfo records allowed a substituted/remapped remaster record to claim ordinal0 while hashing the immutable payload for ordinal1; same-span HED aliases also required explicit row identity.
PayloadInfo now carries immutable internal HED EntryOrdinal and RemasteredOrdinal set by the reader/codec. FromPackage compares both against the requested entry. Regression cases use equal names/stored offsets and HED aliases.

Child accepted a modified raw RelativeOffset on a zero-length BAR record because its physical payload.Offset is normalized to0.
AssetPayload now carries immutable BAR EntryOrdinal/RawOffset/Type/TagHex; Child compares all four. Regression preserves the empty payload but changes the record offset and verifies rejection.

VERIFIED
Selected payloads are opened only through the existing stamped reader, which revalidates file identity and parent/package metadata. Loaded fingerprint locators are descriptive and never used to reopen their saved names.
Identity includes source namespace, nested path, record ordinals, BAR type/tag/raw span and metadata hashes. Alias entries retain distinct locator IDs even when payload hashes and ranges match.
Capture streams in64KiB chunks, enforces declared length including a one-byte overrun check, and disposes the opened stream on all paths. Cancellation is checked during streaming and before digest publication.
JSON has a byte cap, depth cap, entry/path caps, exact required field sets, duplicate-property rejection, ordinal/type/span checks, uppercase hash-shape checks and recomputed locator-ID checks. Missing/null fields do not obtain silent default identities.
SHA256 plus length is the preferred match. MD5 plus length is separately opt-in and labelled LegacyMd5AndLength; loaded digests remain unverified claims about past content, not proof of a current file.
Generic LoadAsync/SaveAsync leave caller streams open. Bounded serialization happens before touching the destination; cancellation while copying can partially write a caller-owned stream, as expected from a stream API.
SaveNewAsync uses a new owned temporary file, held directory handles, repeated path validation and File.Move(overwrite:false). Existing destinations are not overwritten; only its own temporary file is removed on failure.
Fingerprint-file APIs reject explicit UNC/device paths and unsafe Windows destination names; protected directory checks follow Path.GetFullPath. The suspected8.3 bypass was already disproven on this host and the new author-run SaveNew-specific alias test rejects the short alias without creating a file.

LIMITATIONS
