Gummi editor camera tools — v0.10 implementation

Status: source, catalog and isolated tests frozen. No live/game/UI test.

What is implemented
-424 Reset editor camera: calls native290900(currentCamera,10) once. The native 20-unit transition returns to default edit view or preview-entry orientation/FOV. Already-baseline views may remain unchanged.
-425 Preview horizontal FOV: one-time native19DDE0(camera+16,radians,0),20–90 degrees. Only available after normal preview entry. Native controls retain ownership afterward.
-426..430: active phase, current horizontal FOV, target pitch, target yaw, native transition remainder.
Both controls have ValueSlot=-1, no profile replay, no persistence claim, no save or progression write, no automatic undo. RequiresScene=false because the Gummi editor is separate from the field scene.

Numeric contract
Native angle normalization uses repeated +/-2Pi; bounded finite Euler domains prevent non-progress on extreme floats. Reset uses duration10. Focus data is inline and branch-specific; no ship part/grid-cell traversal is required. All actual four-component interpolation endpoints—includingW—must fit the native 20-weight float envelope. CursorW is discarded by24B1D0 and is not artificially constrained. FOV preflight repeats native Float32 tangent/division/atan operations, checks current and destination endpoints, and pins512/416/.5/Pi/2Pi/matrix constants. Viewport dimensions have no arbitrary pixel limit.
