REAL CONTENT AND RETURN MEANING
The table at native0x1407144F0 has eight rows of six 32-byte records. Original CLR
ClassLayout confirms1536bytes. Each record contains text/first-button/second-button
pointers and a DWORDstyle; both nonzero styles1 and2 use the same confirmation.
Information dialogs returnfalse even after acknowledgement. For confirmations,
only the first Windows OK button returns true. Its visible label may be Quit
Game; the second Windows Cancel button may say OK or Retry. Boolean semantics
must therefore be read with the table, not guessed from the displayed label.

ID0: corrupt save to be recreated. ID1: system-data creation failure.
ID2: save failure. ID3: deletion failure. ID4: corrupt data cannot be loaded.
IDs5/6: identical retained Epic Launcher offline text. ID7: retained Epic login
