SCHEDULING
No executable bytes are replaced. A fresh scheduler list is fully validated
before any task callback pointer changes. Checks include owner, previous/next
links, final tail, maximum 2048 nodes, direct callback without continuation,
known task callback, expected group and expected priority.

The outer timing task at RVA 1548E0, group 0, priority 800000 is called exactly
once. Afterwards its fresh positive delta at 717480 is multiplied, capped at 6,
and the inverse at 717488 is recomputed. Native scalar 717424 remains untouched.
Zero, negative and non-finite trainer factors are rejected. Native integer frame
waits are unaffected; this is not a promise of uniform wall-clock scaling.

Camera tasks at RVA 19CBA0, groups 3/5, priorities 30000/90030 are called exactly
once. Camera vectors/FOV are applied before that call rebuilds matrices and
submits them. Only active bank 0 in normal single-camera mode is changed.
FOV setter ABI: RCX projection pointer, XMM1 float radians, R8D horizontal=0.
Vector setter ABI: RCX camera, RDX eye, R8 target, R9 up, all Vec4 pointers.
Free camera is cleared on transitions, menus/events, a changed room/scheduler,
or entry into dual-camera mode. Native camera producers resume after disabling.

Each callback checks the global bridge failure flag, the recorded game-thread
ID, and a host heartbeat at most five seconds old before its own writes.
The original game task still runs even when trainer writes are blocked.

RESTORATION
Reset restores only matching wrapper pointers in newly traversed current lists.
No old task node pointer is retained or dereferenced after scene teardown.
Remaining wrappers are passive if a task cannot safely be restored; the bridge
module remains resident. Other mods' replacement callback pointers are retained.

Render bits snapshot their initial value on first edit. Reset restores only the
owned bit, if its current value still equals the trainer's last write. Other
bits and later differing writes survive. Identical same-bit writes from another
mod cannot be distinguished; the mechanism does not claim perfect ownership
tracking between independent writers. No kh2.cnf file is written.

Actor/effect freeze acquires bit 0x20 at RVA2A11400 only when initially clear.
It binds ownership to room, scheduler and scene heap. Native clears release
ownership instead of being overwritten. Leaving stable gameplay restores the
owned bit only in the same scene. New scene flags are preserved; the native
39C860 -> 3ABAB0 room initialization resets its own flags. A pre-existing native
freeze is rejected. Same-bit writes by independent writers remain ambiguous.

Room transitions and party preset edits are intentional one-shot changes that
can affect the next save. Disable-all does not roll them back. Camera fields are
not restored from a stale scene snapshot; control returns to the native camera.
