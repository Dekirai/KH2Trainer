OFFLINE ASSET EXPLORER — IMPLEMENTATION CONTRACT, 2026-10-04

Scope
Browse loose game assets and the six installed KH2 HED/PKG pairs without a game
process. List exact BAR entries, inspect nested containers, and extract selected
original/remastered payloads to a user-selected destination. Do not call native
game code, patch packages, or run the preserved developer exporters.

Source abstraction (proposed C# Core API; names are negotiable before integration)
AssetSourceKind: LooseFile, PackageOriginal, PackageRemastered, BarEntry.
AssetDescriptor: stable source ID, display name, source kind, logical length,
  optional package/hash, bounded payload locator, immutable parent locator.
BarDocument: header bytes/version, entry count, runtime-base DWORD, auxiliary
  DWORD; IReadOnlyList<BarEntryInfo> and validation diagnostics.
BarEntryInfo: ordinal, UInt16 type, UInt16 link/index field, exact four tag bytes,
  UInt32 relative offset, UInt32 length, optional alias-of ordinal; safe suggested
  filename, friendly type label with provenance, HasNestedBar only after probe.
PackageIndex: HED path, PKG path, HED fingerprint, PKG length/last-write identity,
  IReadOnlyList<PackageEntryInfo> (hash, Int64 offset, Int32 stored/actual lengths).
PackageAssetInfo: header16, original payload and remaster entry descriptors.

AssetExplorer.InspectPackageEntry(PackageIndex, ordinal)

All metadata is independent of Process/BridgeConnection. Use 64-bit stream offsets.
Model/window retains source descriptors, not a permanently open file for each row.
Opening a new source or closing UI cancels previous work. Recheck source identity
when reopening and reject stale locators; never apply offsets from changed files.

BAR on disk (little endian, verified against native code)
0x00: magic bytes 42 41 52, byte3 format/flags. Ordinary corpus magic BAR\x01.
0x04: entry count DWORD (native treats as signed; reject negative/overflow).
0x08: runtime relocation-base field; disk normally zero. Preserve/display raw.
0x0C: auxiliary/motionset field; preserve raw, don't treat it as an address.
Entries start 0x10, stride0x10:
  +0 UInt16 type; +2 UInt16 link/index field; +4 raw four-byte tag;
  +8 UInt32 container-relative offset; +12 UInt32 byte length.
The game mutates +8 header/entry fields into packed pointers after loading.
Do not apply packed-pointer decoding to files or execute the relocation helpers.
Native search matches type and exact DWORD tag; duplicate tags/types are legal.
The native loader skips recursive/type fixups when bit0 of +2 is set. OpenKh
calls this field Index and emits linked entries with reused offsets. Preserve
raw value; identical bounded spans are legitimate aliases, not corrupt files.
Zero-sized entries have no data; accept an offset sentinel of 0xFFFFFFFF only
with zero length. Report rather than dereference any other unsupported sentinel.
Validate the table and every nonempty span before exposing extraction actions.
Nested offsets are relative to the nested container, never the root file.
Native recursive types: 1,17,20,30,46. Also allow a structural BAR probe in other
types, but label that result as format recognition, not engine type semantics.

Retail HED/PKG
HED has no file header; length must be divisible by32. Entry:
 +0 MD5 bytes[16], +16 signed64 package offset, +24 signed32 stored record length,
 +28 signed32 original length. Reject negative/out-of-file spans. Zero stored
 length is a placeholder/unavailable entry; show it and disable decoding.
The hash is a name key, not a content checksum. Optional local kh2idx.txt provides
 exact UTF-8 relative path candidates; only show a resolved name after MD5 match.
Unknown names remain visible as lowercase hash.dat. Name aliases or conflicts
 should be explicit; never infer an original filename from the payload.
At PKG entry offset: four signed32 fields (16 bytes): original decoded length,
 remaster count, stored length/mode, creation value. Then count*48 metadata:
 name[32], offset DWORD, original-asset-offset DWORD, decoded-length DWORD,
 stored-length/mode DWORD. Preserve name bytes and both offset fields as metadata.
Original stored payload starts at entry+16+48*count.
Modes: -2 raw; -1 prefix transform without inflate; positive = transform then
 zlib. Native bypasses transformation/inflate for decoded size<=16. Reject other
 modes until proved; do not silently classify zero as compressed or raw.
Transform: copy16 header bytes; replace each zero byte with its byte index;
 expand 128-bit seed to11 round keys using the native substitution table/key
 schedule, then XOR all11 keys into each complete16-byte block in the first
 min(storedLength rounded down to16,256) bytes. This is not full AES encryption.
Use an independently implemented codec or attributed OpenKh code with its license
 and NOTICE. Do not rely on the presence/loadability of OpenKh assemblies.
Use .NET ZLibStream with an output limit and require exact decoded length; reject
 truncation/corruption and oversized expansion. Stream base payloads when feasible.
Remaster physical offsets are RECOMPUTED by the native prepare function; the disk
 offset field is not a trustworthy physical file position. First remaster offset
 is16+48*count + (mode>=0 ? storedLength : Align16(originalDecodedLength)); each
 next adds prior storedLength when>=0, otherwise Align16(prior decoded length).
Validate every computed span inside the HED record, with checked 64-bit math.
For unknown modes/odd compression alignment preserve metadata and reject decode
 until corpus evidence supports an exact rule. No guessed scanning for zlib data.

UI minimum (English)
Source picker: Game packages / Loose file / Extracted asset folder; search/filter
rows by name/hash/tag/type; breadcrumb for nested BAR; inspector for offsets,
lengths, aliases and recognized signature. Actions: Open container, Extract
selected payload, Copy metadata. Remaster assets form a child list under their
original. Clearly distinguish encoded record extraction from decoded payload.
Do not label generic Type2 as messages: native conversion depends on filepath.
Useful native-backed labels: Type3 BDX script,4 model,7 model texture,9 motion,
10 TIM2,17 animation container,20 motion set,22 event,30 animation map; broader
OpenKh type labels may be shown with separate community-schema provenance.
Initial file recognition can cover BAR, DDS, PNG, TIM2 and signatures actually
read from the corpus. A type label alone does not validate a complete asset.
No 3D preview, texture conversion, model editing or runnable script execution is
implied by this contract. Raw extraction already serves external modding tools.

Bounds and extraction
Suggested default caps:1,000,000 index rows;65,536 BAR children; recursion16;
 metadata16MiB per container; decoded512MiB per payload; prefix-preview64KiB.
Expose limit failures as explicit results, not partial-success containers.
Only inspect nested headers on expansion; do not eagerly decode every package row.
Use exact-span identities to avoid repeated/ancestor recursion. Avoid symlinks/
reparse-point traversal for folder scans and destination resolution.
Never use raw tags/remaster names as filesystem paths. Default to ordinal/type/
escaped tag names. Reject rooted paths, traversal, separators, device names,
alternate streams and Windows trailing-dot/space aliases in any derived path.
Destination must not be the source file/package or inside the selected retail
installation by default. Use create-new temporary files and atomic final move;
no overwrite without a deliberate separate UI choice. Cancellation/error removes
only the temporary file created by this operation. Never delete existing output.

Required tests
Truncated header/table; count overflow; signed negatives; offset+size overflow;
nonempty offset inside table; empty sentinel; aliases; duplicate tags; invalid
tag bytes; nested relative addressing; recursion/cycles; unknown type/version;
HED high offsets beyond4GiB; missing PKG; source changed between inspect/extract;
record metadata overflow; remaster offset recomputation; modes-2/-1/positive;
short transformed tail; zlib error/output bomb/length mismatch; output path attacks;
cancelled extraction and existing destination preservation. Include real small
retail smoke probes privately; do not distribute copyrighted game assets as tests.
