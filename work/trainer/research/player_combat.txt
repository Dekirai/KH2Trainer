DAMAGE AND LIMITATIONS
3C12F0 uses sourceStrength/Magic, targetDefense, limits, difficulty, resistances and
ability modifiers. 3C0FF0 is a separate damage path. No unverified combat hook shipped.
HPfloor+8 is copied into global2A23960 by3C2120, then copied back by3C1D90.
A naive floor toggle can survive actor changes, so this implementation uses AutoHeal.
AutoHeal refills only a living player afterUpdate and cannot prevent lethal damage
that occurs inside an update. It is deliberately labeled AutoHeal.

RESTORATION AND VALIDATION
Continuous refill effects stop on disable or host heartbeat loss. Already restored
HP/MP/timer values are not rolled back. One-time progression changes remain and can
be saved by normal game saving. No automatic position restoration on disconnect.
All enginecalls run on the checked game thread after successful original Update.
Research was read-only; no game process writes or live feature execution were done.
Isolated native tests use allocated fake game/status/actor memory.
