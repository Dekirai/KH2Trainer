Gummi editor implementation — independent review
================================================
Result: no remaining blocking findings in the frozen source.
Reviewer: pe_inventory. No product edits, build or live action.

Resolved findings
- Fallback focus and retained focus could enter the new20-unit transition with finite inputs whose float32 weighted intermediates overflow.
  WeightedVectorFinite now validates all four retained/center/grid components. Active cursor XYZ bounds retain the existing envelope. Regression cases cover center fallback, retained focus and homogeneous components.
- Reset validated only the saved target projection, allowing an invalid current projection endpoint before interpolation.
  ResetReady also checks current FOV and, for edit mode, the preserved2596/2600 endpoints. Tests include a tiny current angle with finite saved target and malformed preserved endpoints.

Confirmed behavior
- The main module, heap aliases, editor/work/camera/cursor objects and backlinks are validated. Both native scheduler lists are traversed to their exact tails with manager ownership, predecessor links, nondecreasing priority and a2048-node bound; no current dispatch may be active. Required owner tasks must each be unique, with exact callback/cleanup/group/priority and correct fiber kind.
- Acyclicity follows from the required predecessor links starting at null plus bounded full traversal. Module membership has its own explicit seen-array bound. No native lookup that might create a named camera record is called.
- The named-camera registry validates free-index bounds/uniqueness, bounded strings and exactly one occupied matching camera. The module and object owner tuple is rebuilt and compared immediately before dispatch.
- Reset ABI is void(camera RCX,int10 EDX). FOV ABI is void(camera+16 RCX,float radians XMM1,int0 R8D). Incidental native reset return registers are ignored. Command dispatch executes exactly one requested native call after two complete numeric/owner/code preflights, then returns only static status text without further borrowed-state reads.
- Projection preflight follows the native scalar float order:512/width times0.5,416/height times0.5, tangent(angle*0.5), focal, ratio and doubled atan. Width/height and all intermediates must be positive finite. FOV action remains limited to preview phase4/mode1 and20..90degrees.
- Reset yaw/default angles are finite and bounded before native normalization loops. Focus spans cover every inline helper read; no grid-cell or ship-part list traversal is introduced by the selected native path.
- Native282FA0 computes a temporary4D cursor translation, but24B1D0 first copies the complete GRID focus and replaces only one XYZ component. The temporary cursor W is discarded; effective focus W comes from GRID, center fallback or retained camera focus. Final tests reject unsafe used W values while accepting a discarded cursor-W overflow.
- Snapshot now applies HostReady before Build, while paused module state2 can still provide diagnostics. Actions require active state1, no input lock and no pending view transition. Sora sceneReady is intentionally irrelevant to this menu context.
- Exact original-byte comparison independently matched all41 compiled code/data pins (4107 bytes). Direct engine helper pins cover the selected synchronous reset/projection path; ordinary imported CRT trigonometric behavior remains an environmental dependency.
- Actions are one-time native state changes. They introduce no observer hook, persistent pointer cache, force-cleared native lock, automatic restore, progression change or profile replay.

Validation
Author reported756 checks,0 failures,/W4 without warnings. Test source was independently read; no second build was run.
All41 code/data pins (4107 bytes) were independently compared with the original EXE and matched.
Fourteen selected full ASM bodies read: 493 instructions. Additional saved pseudocode was used only for the explicitly listed consumer/lifecycle context.

Limitations
- No authorized live visual test occurred. Synthetic callback stubs demonstrate dispatch and preflight behavior, not execution of the original native function bodies.
- Object identities are not generation tokens. Normal serialized engine-thread lifetime is required; arbitrary foreign-thread destruction or modifications remain outside the contract.
- Numeric bounds are conservative preflight policies and do not claim acceptance of every corrupt or customized editor state.
- Native input, view reset and editor exit can immediately replace one-time values; no persistent camera override is promised.
- This review does not claim complete semantics of all Gummi editor functions or re-review unrelated undo/redo/export operations.
