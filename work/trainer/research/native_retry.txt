PROGRESSION ROLLBACK
3A0580 copies backup progression into live SaveData via39FF70, restores both
auxiliary blocks, clears battle/cache state, refreshes configuration/audio and
invalidates world caches. Inventory, levels, EXP, abilities, quest flags and
other SaveData can revert. This is the game's retry checkpoint, possibly in an
earlier room. It is not an arbitrary combat rewind or VM state snapshot.

SAFE NATIVE ENTRY PATH
Native menu151000 action2 calls3A0520 to retrieve the ten-byte target and then
152990(&target,1,0,1,0). The trainer uses those exact arguments.
ABI: RCX target pointer, EDX flags1, R8D delay0, R9B restore1, stack DWORD
signal0; ignored integral return. Function copies the target before returning.
Its scheduled transition152A90 waits for menu/event closure, marks scene unready,
removes gameplay tasks, destroys actor/resources and frees the scene heap before
calling3A0580. It then queues the normal field reload. Calling3A0580 immediately
from an arbitrary combat frame would violate this ordering and is not done.
Game-over3FCBE0(2) uses a different flags/delay pair and clears game-over state;
the trainer deliberately follows the menu retry entry point instead.

TRAINER GATES

module716884=1, no pending transition9BA928, menu9006B0=0, eventAC0F48=0,
and readable live field scheduler716868.
Requires readable complete backup, target and both auxiliary blocks.
Both live SaveData9A98B0 and backup headers must be QWORD0x0000003A4A32484B
(KH2J / version58). Backup location bytes+12..14 must match the checkpoint.
Target world0..18/room0..63 must exist in the live area table2A10558.
Native checkpoint mission spawn sets are preserved as signed16-bit values;
manual travel bounds -1..50 are not imposed on native mission checkpoints.
CRC is not validated because checkpoints copy mutable live SaveData; its CRC
can be stale until export2ED110 finalizes it. No save-export call is introduced.

RESTORATION AND UI
Trainer-owned actor freeze is released and free-camera hold is stopped before
the transition request. Retry is an intentional one-shot progression change,
not undone by Disable All. It writes no save file directly; a later normal save
can persist the restored progress. UI ChangesProgression=true and explicit
description warn about inventory/EXP/abilities/other rollback.
